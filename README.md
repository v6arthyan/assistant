# VSix Assistant

A no-build, no-paid-API guided assistant for V6 Arthgyan LLP.

## Included

- Investor desk: prepared English/Hindi answers about SIPs, KYC, mutual fund basics and risk, with AMFI links.
- WhatsApp contact link: +91 6306522855. Opening the link never sends a message automatically.
- Team toolkit: general onboarding, service, content-review and handover checklists.
- Editable communication templates: caption, SIP enquiry, service follow-up and internal handover.
- SIP mathematical illustration using end-of-month contributions and an effective monthly rate.
- Responsive layout, keyboard-accessible controls and mandatory brand/disclaimer footer.

## Limits

This is keyword routing and prepared content, not a generative AI model. Unmatched questions receive an explicit fallback. No live NAVs, account access, transaction execution, document upload, staff authentication, CRM, lead database or portal integrations. Team mode is a public toolkit, not a protected employee area. Do not add confidential client records or secrets.

Chat and drafts stay in page memory and reset on reload. No analytics or browser persistence is included. External AMFI and WhatsApp links navigate to their respective services. Do not enter sensitive information. Numeric input detection is a convenience notice, not a data-loss-prevention control.

## Run

Serve `dist/` using any static web server. There are no dependencies, build steps, API keys or paid model services. Hosting-provider free limits and terms apply separately.

## GitHub Pages option

The repository-root index.html, style.css and app.js are copies of the deployable static files. Configure GitHub Pages to serve the main branch root in repository settings. GitHub Pages has not been enabled by this code commit. A separate private preview can be used for review.
